# 🌌 Velvet Dusk

An aesthetic, modern dark theme featuring deep velvet slate surfaces, soft pastel lavender to dusty rose gradient borders, zero-rounding sharp window styling, and high-contrast pastel typography.

![Preview](preview.png)

## ✨ Features

- **Window Borders**: Elegant 90° gradient transitioning from soft **Pastel Lavender** (`rgba(BFA7DBff)`) to **Dusty Rose Pink** (`rgba(C18FB1ff)`).
- **Sharp Modern Look**: Zero-rounding borders (`rounding = 0`) for a crisp, clean tiling window aesthetic.
- **Deep Velvet Slate**: `#1E1E2E` base with `0.90` opacity and blur across terminals and popups.
- **Comfortable Typography**: Luminous lavender-white (`#CDD6F4`) for maximum readability and zero eye fatigue.
- **Curated Wallpapers**: 3 high-resolution anime backgrounds included in `backgrounds/`.
- **Discord / Vesktop Theme**: Complete Vencord theme matching Velvet Dusk with soft lavender and dusty rose accents.

## 🚀 Installation

### Using Omarchy

```bash
omarchy theme install https://github.com/m7sh/velvet-dusk-theme.git
omarchy theme set "Velvet Dusk"
```

### Manual Installation

Clone into your Omarchy themes folder:

```bash
git clone https://github.com/m7sh/velvet-dusk-theme.git ~/.config/omarchy/themes/velvet-dusk
omarchy theme set "Velvet Dusk"
```
